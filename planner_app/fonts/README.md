# Bundled fonts

Every font here is free to bundle and redistribute in the app. Each one's licence
is in `licenses/`.

| File | Family | Licence | Replaces |
| --- | --- | --- | --- |
| `BebasNeue-Regular.ttf` | Bebas Neue | SIL OFL 1.1 | This Appeal (demo) |
| `Allison-Regular.ttf` | Allison | SIL OFL 1.1 | Restweek (personal use only) |
| `PermanentMarker-Regular.ttf` | Permanent Marker | Apache 2.0 | Rocket Brush |
| `Bungee-Regular.ttf` | Bungee | SIL OFL 1.1 | Jraot |
| `BungeeOutline-Regular.ttf` | Bungee Outline | SIL OFL 1.1 | Jraot Outline |
| `BungeeShade-Regular.ttf` | Bungee Shade | SIL OFL 1.1 | Jraot Hollow, Jraot Extrude |

All of them come from the [Google Fonts repository](https://github.com/google/fonts).
When adding a font, add its licence to `licenses/`, add it to `BUNDLED_FONTS` in
`planner_app/settings.py`, and only use fonts whose licence allows bundling in
distributed software.
